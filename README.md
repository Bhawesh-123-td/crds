# CRDS Nepal Website — Version 1 Prototype

This is a static, responsive V1 redesign prototype based on publicly available CRDS Nepal website content.

## Included
- Responsive homepage
- About / mission / vision
- Six program pillars
- Project cards and filters
- Impact section
- Resources / transparency section
- News and vacancy archive concept
- Donation CTA
- Contact form UI
- Mobile navigation
- Basic accessibility foundations
- SEO-ready title and meta description

## Important before production
1. Verify all CRDS facts, project statuses, impact figures, names and contact details.
2. Replace the demo contact form with a secure backend or CMS form.
3. Replace placeholder visual artwork with approved CRDS photography.
4. Add the actual annual reports, audit reports, policies and project documents.
5. Run a full broken-link, accessibility, performance and security audit.
6. Set 301 redirects for retired/duplicate URLs such as `/new-home-page/` after confirming the final URL map.
